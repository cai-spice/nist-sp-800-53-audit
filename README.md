<h1>NIST SP 800-53 Media Protection Audit of Contoso</h1>

<h2>Description</h2>
This project consists of an audit done on a fictional healthcare company called Contoso. During this project I prepared, executed, and reported an audit of a subset of NIST SP 800-53 cybersecurity controls to include interview, document review, and testing of systems to support compliance audit activities.
